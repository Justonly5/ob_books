## OpenAI 协议接口
OpenAI API 有多个接口类型。对于开发 Agent 的场景，最重要的是以下几个。

| 接口                   | 主要用途                 | 建议       |
| -------------------- | -------------------- | -------- |
| Responses API        | 文本、多模态、工具调用、Agent 交互 | 新项目优先    |
| Chat Completions API | 基于 `messages` 的聊天补全  | 兼容已有项目   |
| Embeddings API       | 将文本转换为向量             | RAG、语义检索 |
| Realtime API         | 低延迟语音、实时交互           | 语音 Agent |
| Audio API            | 语音转文字、文字转语音等         | 语音处理     |
| Images API           | 图像生成和相关任务            | 图像应用     |

### **最常见的 OpenAI 兼容接口：Chat Completions**
这是很多第三方模型服务、模型网关以及开源 Agent 都支持的接口形式。
#### **1. HTTP 基本规范**
Method：POST
请求地址：`https://api.openai.com/v1/chat/completions`
请求头：
`Content-Type: application/json`
`Authorization: Bearer YOUR_API_KEY`
请求体：`JSON`
响应：`JSON`，或启用流式输出后返回 `text/event-stream`
官方参考：[Create chat completion](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create?utm_source=chatgpt.com)。

## SSE 协议
SSE 是一种标准的 HTTP 流式传输格式，服务端通过空行分隔每个事件。
