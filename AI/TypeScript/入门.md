# 安装
```BASH
pnpm install -g typescript
```
验证：
```BASH
tsc -v
```

编译：
```bash
tsc hello.ts
```
TypeScript 编写的文件以 `.ts` 为后缀，用 TypeScript 编写 React 时，以 `.tsx` 为后缀。

# Hello world

```ts
function sayHello(person: string) {
    return 'Hello, ' + person;
}

let user = 'Tom';
console.log(sayHello(user));
```

# QuickStart
## 1. 创建项目目录
```BASH
mkdir my-ts-project
cd my-ts-project
pnpm init
```
`pnpm init` 会创建 `package.json`，用于管理项目依赖和脚本。
## 2. 安装 TypeJS 及开发工具
项目目录下执行：
```BASH
pnpm add -D typescript tsx @types/node
```
这三个包分别负责：

| 包             | 作用                               |
| ------------- | -------------------------------- |
| `typescript`  | 提供 `tsc` 编译器和类型检查                |
| `tsx`         | 开发时直接运行 `.ts` 文件                 |
| `@types/node` | 提供 Node.js API 的 TypeScript 类型定义 |
这里使用 `-D`，表示将它们放入 `devDependencies`。
这个会新建 `pnpm-lock.yaml`、`pnpm-workspace.yaml` 文件。
## 3. 创建项目目录结构
执行：
```bash
mkdir src
touch src/index.ts
```

## 4. 配置 TypeScript 编译器
创建 `tsconfig.json`：
```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "rootDir": "src",
    "outDir": "dist",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "sourceMap": true
  },
  "include": ["src/**/*.ts"]
}
```

几个关键配置：
- `target`：编译生成的 JavaScript 使用什么语言版本。
- `module`：采用 Node.js 的 ES Module 模块规则。
- `rootDir`：源代码目录。
- `outDir`：编译输出目录。
- `strict`：启用严格类型检查，建议新项目开启。
由于这里使用了 `NodeNext`，还需要在 `package.json` 中声明模块类型。
## 5. 配置 `package.json`
保留 pnpm 初始化时生成的 `name`、`version` 等字段，在其中加入下面的配置：
```json
{
  "type": "module",
  "scripts": {
    "dev": "tsx src/index.ts",
    "build": "tsc",
    "start": "node dist/index.js",
    "check": "tsc --noEmit"
  }
}
```

这是需要合并进去的配置，不要直接用它覆盖已有的依赖字段。
各命令的作用：

| 命令           | 作用                 |
| ------------ | ------------------ |
| `pnpm dev`   | 直接运行 TypeScript 源码 |
| `pnpm build` | 将 `.ts` 编译成 `.js`  |
| `pnpm start` | 运行编译后的 JavaScript  |
| `pnpm check` | 只检查类型，不生成文件        |

三个文件的职责：
- `package.json`：项目需要什么、有哪些命令。
- `pnpm-lock.yaml`：依赖最终解析成了哪些具体版本。
- `tsconfig.json`：TypeScript 应该如何进行类型检查和编译。
## 6. 编写第一个 TypeScript 程序
编辑 `src/index.ts`：
```js
interface User {
  id: number;
  name: string;
}

function greet(user: User): string {
  return `Hello, ${user.name}!`;
}

const user: User = {
  id: 1,
  name: "Tom"
};

console.log(greet(user));
```

## 7. 运行项目
先直接运行：
```bash
pnpm dev
```
预期输出：
```bash
Hello, Tom!
```
然后执行类型检查：
```bash
pnpm check
```
编译：
```bash
pnpm build
```
编译成功后，会生成：
```
dist/
└── index.js
```
最后运行编译结果：
```bash
pnpm start
```
同样会输出：
```
Hello, Tom!
```
