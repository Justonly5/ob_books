
## 通过 `npm` 运行
```sh
npx @deepseek-ai/dsh web
```

## 源码运行
```bash
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```

**`pnpm dsh web`** = 用 `pnpm` 执行根 `package.json` 中 `bin` 定义的 `dsh` 命令，即：

```BASH
node --import tsx/esm apps/cli/src/bin.ts web
```
